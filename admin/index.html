Sign in with a GitHub access token

The dashboard saves changes to the GitHub repository . Each person uses their own token, so every change shows who made it.

  1. Open GitHub → Settings → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → this repository.
  3. Permissions: Contents: Read and write, Pull requests: Read and write, Commit statuses and Checks: Read (if listed).
  4. Generate, copy, and paste it here. It's kept only in this browser and sent only to api.github.com.
